Tripy Mobile App

Mobile development 2019

A travel companion that helps people plan trips without the spreadsheet. Built with React Native on the client and a Node.js API behind it.

cat ./tripy/details.md

Overview

Tripy started as a weekend project and grew into a full mobile application: a way for a small group of friends to plan a shared trip — destinations, dates, budget and packing notes — in one place instead of across chat threads and notes apps.

This page is the structure I use to present a project: what it is, what problem it solves, and the decisions behind the stack. Replace the copy and imagery here with a project you want to feature.

The backend

The API is a Node.js service that owns trips, members, and checklists. It exposes a small, predictable REST surface, keeps state in MongoDB, and handles the group-membership rules in one place.

  • REST API for trips, members and items, versioned from day one.
  • MongoDB for flexible trip data that changes shape as the app grows.
  • Token-based auth so each group only sees its own trips.

Client & integration

The React Native client talks to the API over a thin data layer, so screens stay readable and the backend contract stays honest. Offline-first basics — optimistic updates for checklist items — make it feel fast even on a weak connection.

  • React Native with a typed data layer in front of the API.
  • Optimistic checklist updates with reconciliation against the server.
  • Reusable screens for plans, maps and members.
