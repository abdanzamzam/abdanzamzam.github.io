check-disposable-email

An npm package that checks whether an email address is disposable or temporary — a simple, reliable way to detect throwaway email services used for one-time registrations, spam, or trial abuse.

  • Fast lookup against known disposable email domains.
  • Zero-config API — pass an email, get a verdict.
  • Useful for signup flows, lead forms and fraud checks.

strapi-import-export-entries-customize

A customization plugin for Strapi that imports and exports data in a few clicks — including base64 images via CSV, for special needs.

  • Import/export entries directly from the admin panel.
  • Handles base64 image imports through CSV.
  • Built for the Strapi headless CMS ecosystem.

react-express-view

A template engine for Express that renders React components as client-side views — bringing React into server-rendered Express apps with minimal friction.

  • Drop-in view engine for Express + React.
  • Renders React components as views, not just SPAs.
  • Lightweight and framework-agnostic on the client side.

npmjs.com/package/react-express-view →
